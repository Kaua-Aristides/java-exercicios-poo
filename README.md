# 📘 Exercícios em Java

Este repositório contém meus exercícios e pequenos projetos desenvolvidos durante meus estudos em **Java**, com foco em fundamentos da linguagem, **Programação Orientada a Objetos (POO)**, **banco de dados** e introdução ao **JPA**.

## 🎯 Objetivo

Praticar lógica de programação, consolidar conceitos de Java e construir uma base sólida para oportunidades como **estágio** ou **desenvolvedor Java júnior**.

## 📚 Conteúdo

* Fundamentos da linguagem Java
* Entrada e saída de dados
* Estruturas de controle
* Classes e objetos
* Métodos e responsabilidades
* Programação Orientada a Objetos (POO)
* Exercícios com banco de dados usando JDBC
* Operações CRUD:

  * Inserir dados
  * Consultar dados
  * Atualizar dados
  * Deletar dados
* Introdução ao JPA
* Persistência de dados e manipulação de entidades

## 🛠️ Tecnologias

* Java
* JDBC
* JPA
* MySQL
* Eclipse
* Git & GitHub

## 🚀 Em evolução

Este repositório está em constante atualização conforme avanço nos estudos e adiciono novos exercícios e projetos.
